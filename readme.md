# Breast Cancer Prediction Deployment using Flask

## Project Overview

This project deploys a Machine Learning model for breast cancer prediction using Flask. The application allows users to input tumor feature values through a web interface and receive real-time prediction results.

The deployed model predicts whether the tumor is:

- Malignant Cancer Detected
- Benign Tumor

This project demonstrates practical implementation of:
- Machine Learning
- Model Deployment
- Flask Web Development
- Frontend and Backend Integration

---

# Features

- Real-time breast cancer prediction
- Flask-based web application
- Interactive user interface
- Machine learning model integration
- Model deployment workflow
- Prediction result display
